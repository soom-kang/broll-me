# Package sources and scope

Keep the software, font and icon notices when distributing `broll-me`. [LICENSE](../LICENSE) contains the retained MIT copyright and permission text. [Third-party notices](../THIRD_PARTY_NOTICES.md) identifies the bundled fonts and icon data.

## Workflow reference

The workflow draws inspiration from [HyperFrames’ motion-graphics skill](https://github.com/heygen-com/hyperframes/blob/main/skills/motion-graphics/SKILL.md), including preparing a scene, inspecting proof frames and rendering deliverables. This names a workflow reference and makes no code-source claim.

## Palette references

The supplied 꾸밀걸 CI board specifies primary `#FF5C8D`, rose `#FF8FA6`, coral `#FFCDB5`, cream `#FFF0E6` and white `#FFFFFF`. `kkumil-pink` retains those decorative values and adds text roles for graphic contrast. Separate application cream values do not replace the CI cream.

`onnimm-orange` uses the ONNIMM UI primary `#FF8A50`, with apricot and honey decoration. The other presets are authored graphic themes. These palettes do not establish official brand approval or certify a match to a production screen.

The package contains color values and explanations. It excludes private CI boards, logos, photographs and footage. Artwork supplied for a video remains a separate input with its own redistribution rights.

## Fonts and runtime

The bundled [Noto Sans KR](https://github.com/google/fonts/tree/b38c5c93af322c45f633e17ac440ec1e6c94d489/ofl/notosanskr) comes from Google Fonts revision `b38c5c93af322c45f633e17ac440ec1e6c94d489`. Its SHA-256 is `194018e6b2b293a7964f037b25c0249ce1418bc9ab3c971060a03aa57861e252`; keep its OFL notice. Geist and Geist Mono cover Latin UI text, with Noto Sans KR as the Korean fallback.

Runtime components install into a separate project folder. The package requires no model API client or credentials. Codex and Claude Code share the CLI and portable frontmatter; host metadata resides in `agents/openai.yaml`.

## Keep evidence distinct

Report local rendering, archive checks, actual host invocation and human visual approval separately. The recorded fixture requests completed in Claude Code and were blocked by Chromium permissions in Codex. Those records do not prove real speech alignment or approve a final edit.
